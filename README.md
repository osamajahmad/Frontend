# Frontend Projects

A collection of frontend web development projects built using **HTML, CSS, and JavaScript**.

This repository includes two multi-page websites created to practice responsive design, page structure, styling, navigation, interactive JavaScript features, forms, and media handling.

---

## Projects

### Switzerland Travel Website

A multi-page travel website focused on Switzerland as a tourism destination.

The website presents destinations, activities, and travel-related information using responsive layouts, cards, images, video, audio, and interactive filters.

### Features

* Multi-page website structure
* Responsive navigation bar
* Destination cards
* Activity cards
* Category filtering using JavaScript
* Video controls
* Background audio controls
* Contact form
* HTML form validation
* CSS hover effects
* Responsive layouts using Flexbox and Grid
* Reusable page styling

### Pages

* Home
* Places to Go
* Things to Do
* Contact Us
* References

---

## Fortnite Fan Website

A multi-page informational website focused on Fortnite.

The website organizes game-related information across different pages using images, tables, cards, navigation links, and responsive layouts.

### Features

* Multi-page navigation
* Responsive page layouts
* Card-based content sections
* Image galleries
* Structured tables
* Hover effects
* Responsive CSS
* Semantic HTML structure

### Pages

* Home
* Drop Spots & Loadouts
* Vehicles & Weather
* Characters & Zone Strategy

## Running the Projects

No installation is required.

Clone the repository:

```bash
git clone <your-repository-url>
```

Open either project folder and open:

```text
index.html
```

in your browser.

For a better development experience, you can also run the projects using a local server.

### Using Python

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

You can also use an extension such as **Live Server** in Visual Studio Code.
